# ゲーム制作①

## ペットボトル・ギャラクシー

赤いペットボトルが宇宙でエイリアンと戦う、ブラウザで遊べるシューティングゲーム。

### 起動方法

`src/index.html` をダブルクリックしてブラウザで開くだけ(インストール不要)。

### 遊び方

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | 矢印キー / WASD | 画面をドラッグ |
| ショット | 自動 | 自動 |
| 炭酸バースト | SPACE(ゲージ満タン時) | 右下のボタン |
| 一時停止 | P / Esc | - |

- **振って炭酸チャージ**: 左右にすばやく切り返すと炭酸ゲージがたまる。
- **炭酸バースト**: 敵を貫通し、まわりの敵弾を消し、ボスに大ダメージ。
- HP はボトルの水の量(3)。ステージクリアで 1 回復。
- 全5ステージ: ステージ3に中ボス、ステージ5に大ボス。進むほど難しくなる。

### ファイル構成

- `src/stages.js` … ステージ定義(難易度の数値はここで調整)
- `src/player.js` … ペットボトル(自機)
- `src/enemies.js` … エイリアン・ボス
- `src/main.js` … ゲーム進行・入力・描画
